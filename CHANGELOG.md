# Changelog

**[English](CHANGELOG.md) · [Русский](CHANGELOG.ru.md)**

Downloads and publication dates are available in [GitHub Releases](https://github.com/mrPortnov/NUMA-Control/releases).

## 1.7.0 — launcher integration

- Launch games through Epic Games, Battle.net and Ubisoft Connect using supported links or game shortcuts.
- Find the Epic launch link automatically for Fortnite profiles with the default launch target.
- See which operation Windows denied and whether the requested CPU mask was confirmed.

## [1.6.1 — BIOS list readability](https://github.com/mrPortnov/NUMA-Control/releases/tag/v1.6.1)

- White text on blue highlighted dropdown items in AMI BIOS, including keyboard navigation and an already selected item.
- Improved profile-editor label contrast in Light and AMI BIOS themes.
- Core, thread and group counts removed from the About version line.
- English and Russian documentation, with complete theme previews and updated screenshots.
- Both languages of the user documentation included in MSI and portable packages.
- Added a VAC-only compatibility warning and an explanation of the Windows APIs used, without DLL/code injection or game-memory access.

## 1.6.0 — language selection and prerequisite setup

- Russian / English selection in Settings, applied immediately and remembered after restart.
- Translated pages, editors, dialogs, tooltips, diagnostics and tray menus. User-entered names and existing log entries are preserved.
- Separate English and Russian interface screenshots.
- Setup detects .NET Framework 4.8+ and downloads the official Microsoft prerequisite when absent. Standalone MSI and portable ZIP remain available.

## 1.5.0 — first GitHub release

- Game profiles, manual CPU affinity, physical-core topology and presets, process monitoring, tray operation and self-diagnostics.
- Four themes, profile import/export, data recovery, game launching and shortcuts.
- Portable distribution and per-user MSI.
- English and Russian README with interface screenshots.
